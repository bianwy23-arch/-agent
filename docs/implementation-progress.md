# 第一阶段实现记录

日期：2026-09-09。所有代码在独立仓库新建，没有复制旧项目实现。

本文保留第一阶段交付时的历史状态；后续 SDK、DeepSeek、网页和真实检查进展见 [第二阶段接入记录](deepseek-integration.md)。下文“尚未实现”是第一阶段时点，当前能力以第二阶段记录为准。

## 已实现

- `state.py`：SQLite 保存任务、用户轮次、正式需求、候选事实、待澄清项、一个临时探索方案、展示批次、修改历史与应用回执。
- 按组原子应用；非法组不写入，允许改正后重试；已成功组重复提交不重复应用，同一 ID 换内容拒绝。
- 按字段恢复需求或撤销上一轮已应用修改；保留无关修改和后来事实。恢复写成新事件，支持重启后继续。部分撤销会拆开依赖组时拒绝，等待上层处理。
- 待澄清部分可独立取消；仅有待澄清项的上一轮不会使默认撤销误伤更早修改。
- 临时探索不覆盖正式需求；未知字段与明确无偏好不同；任务数据隔离；展示 ID/顺序不可被新排序覆盖。
- `catalog.py`：加载冻结数据，检查文件哈希、商品/来源一一对应、历史 USD 价格与属性证据片段。读取数据实际为 12 类 × 50 条。
- 商品查询提供完整品类/预算/排除过滤及明确标注的简单文本匹配；证据查询保留原文上下文，缺失信息返回 unknown。

## 尚未实现及不能据此声称的能力

- 本阶段提供确定性服务，**没有接入 OpenAI Agents SDK、DeepSeek 或自然语言解析**，也没有网页。测试输入是结构化操作，不是模型自主运行。
- 结构校验和原话引用校验不证明自然语言语义已经正确理解；推断/默认来源与依赖失效重算尚未接入。当前更新 API 只接受明确来源，不把推断标为用户明确要求。
- 条件性预算、复杂条件、软偏好排名、自动澄清决策、最终推荐核验、无进展策略仍待实现。结构中未支持的条件明确拒绝，不静默丢弃。
- 状态变化会保留事实并把候选资格标为 unknown、结论标为需重评；尚未自动完成全约束资格重算。搜索仅保证返回的结构化过滤范围，不代表商品满足所有要求。
- 文本检索是大小写不敏感的词包含匹配，不是中文语义召回。关键词无结果不等于目录无匹配。
- 一个临时探索对象保存其正式需求版本；后续模型接入须处理版本变化后的探索有效性，当前不提供自动接受临时方案的捷径。
- 决策对象目前只是初始结构，用户选择/讨论对象更新及多任务自动路由仍需上层实现。
- 尚未生成或执行 40～60 个模型任务，未完成 3 个真实 Agent 故障修复记录。原文片段校验的实现修正不包装成 Agent 业务故障。

## 验证方式

在仓库根目录执行：

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

检查覆盖局部预算恢复与新事实保留、整轮撤销、待澄清取消、错误更新组原子性、重试、依赖组撤销限制、临时方案隔离、重启持久化、多任务隔离、展示指代、未知/无偏好、来源与商品 ID 校验，以及真实商品数据的过滤和证据边界。

该命令只运行程序级测试，不访问模型 API；数据库写入测试临时目录，不修改商品快照。
